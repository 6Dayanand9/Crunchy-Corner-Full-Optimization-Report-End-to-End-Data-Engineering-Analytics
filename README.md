## Crunchy Corner – End-to-End Data Engineering & Analytics Pipeline

This project demonstrates a **complete end-to-end data engineering and analytics solution** built using **Microsoft Fabric** and **Medallion Architecture (Bronze–Silver–Gold)** for scalable, analytics-ready data processing.

### 🔹 Project Overview

The pipeline ingests raw business data, performs structured transformations, and delivers validated gold-layer datasets optimized for business intelligence and reporting.

### 🔹 Architecture & Workflow

* **Data Ingestion**: Raw data is ingested using Fabric Copy Data into the Lakehouse.
* **Silver Layer**: Data cleaning, standardization, and transformation are performed using Fabric Notebooks.
* **Gold Layer (Dimensions)**: Dimension tables are created to support analytical queries.
* **Gold Layer (Fact Tables)**: Fact tables are built using Dataflows for optimized reporting.
* **Validation Layer**: Final data quality checks and validations ensure accuracy and consistency before consumption.

### 🔹 Key Features

* End-to-end orchestration using **Fabric Pipelines**
* Implementation of **Medallion Architecture**
* Scalable and modular notebook-based transformations
* Data quality validation before BI consumption
* Analytics-ready datasets for reporting tools like **Power BI**

### 🔹 Technologies Used

* Microsoft Fabric
* Lakehouse
* Fabric Pipelines
* Fabric Notebooks
* Dataflows
* Power BI

### 🔹 Use Case

This solution is designed to support **business intelligence, performance analysis, and decision-making** by delivering clean, reliable, and well-modeled data.
